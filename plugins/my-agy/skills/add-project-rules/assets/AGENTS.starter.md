# Project Rules (AGENTS.md)

Guidelines and rules for AI assistants working in this repository.

## Environment & Tooling
- Use `mise` for environment variables and tool runtimes (`mise.toml`).
- Use `just` as the canonical task runner (`justfile`). Prefer defined recipes over raw commands.

## Code Style & Commits
- Commit messages follow Conventional Commits: `type: 日本語の概要`.
- Keep replies and explanations concise and focused on code changes.
